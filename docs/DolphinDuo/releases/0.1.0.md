The first release of **Dolphin Duo**, a fork of Dolphin for dual-screen Android handhelds such as
the AYN Thor. The game runs on the top screen, and the bottom screen shows a live, touchable
companion for the game you're playing.

![Dolphin Duo on an AYN Thor](https://raw.githubusercontent.com/CMApex/dolphin-duo/master/docs/DolphinDuo/images/thor.jpg)

## What's in it

- **Companion screens** on the second display. They are drawn from small declarative packages,
  read the game's memory between frames, and can be tapped to switch pages.
- **Fire Emblem: Path of Radiance (`GFEE01`)**, the first companion:
  - a live war-map minimap
  - the unit under the cursor, with portrait, stats and items
  - army roster and full status pages
  - battle and scene views

  It's drawn in the game's own style, using art and text read from **your own disc image**. None
  of the game's assets ship with Dolphin Duo.
- **The Inspector** for every other game: game ID, revision and live memory watches.
- **Manage Companions** (Settings → Interface → Dolphin Duo) to install or remove companions,
  plus switches to turn the companion screen off and to control whether companions may change
  game memory. Memory changes are always blocked in RetroAchievements hardcore mode.
- **Tools for making companions**: `dolphin-tool duo validate|preview`, a desktop page renderer,
  a headless scripting harness, a template and the full format reference in
  [docs/DolphinDuo](https://github.com/CMApex/dolphin-duo/tree/master/docs/DolphinDuo).

## Installing

1. Download `dolphin-duo-0.1.0-arm64.apk` below and install it. It installs as **Dolphin Duo
   Debug**, next to regular Dolphin rather than replacing it, and newer Dolphin Duo test builds
   install over it.
2. Download `fe9-path-of-radiance.zip` below and install it from **Settings → Interface → Dolphin
   Duo → Manage Companions**.
3. Start Path of Radiance (NTSC-U, `GFEE01`) from a disc image. The companion appears on the
   second screen.

## Tested

On an AYN Thor:
- The companion appears on the bottom screen.
- Live values match the game.
- Disc art and text load.
- Taps work.
- There's no noticeable performance cost.
- Backgrounding and resuming work.

With Duo turned off, and on a single-screen phone, it behaves like regular Dolphin.

## Good to know

- This release is built like the test builds: arm64 only, and signed with the project's public
  test key (hence "Debug" in the name). A build with its own release key and app ID may come
  later. It would install as a separate app.
- Path of Radiance doesn't yet show live HP during battle animations, grey out units that have
  acted, or cover the base and preparations screens.
